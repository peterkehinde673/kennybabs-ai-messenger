# 🤖 Kennybabs AI Messenger v1.0.0

An autonomous AI agent and P2P messaging application built on the official **Unicity Sphere SDK** (`@unicitylabs/sphere-sdk` v0.14.3) and **Google Gemini AI**.

## 🌐 Live Control Center
**Access the dashboard here:** [https://peterkehinde673.github.io/kennybabs-ai-messenger/](https://peterkehinde673.github.io/kennybabs-ai-messenger/)

## 🚀 Architecture
- **Backend Agent:** Persistent Node.js/TypeScript autonomous service running on Unicity Testnet2 with P2P Nostr DM listeners and Gemini AI reasoning.
- **Frontend Dashboard:** Real-time monitoring Control Center displaying agent status, network parameters, and live event telemetry.
